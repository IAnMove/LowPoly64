Comprobando el análisis local…

Cómo activar el análisis de mis audios

En la carpeta de Retrovisor, instala el motor una vez con npm run rhubarb:install. Arranca la aplicación con npm run dev, abre la dirección local que aparece y pulsa «Comprobar de nuevo». La instalación descarga el motor; tus grabaciones se analizan en tu equipo.

En una web estática puedes escuchar la frase con gestos preparados, importar movimientos JSON y exportar personajes hablando. Para calcular gestos de una grabación nueva, usa Retrovisor en local.
