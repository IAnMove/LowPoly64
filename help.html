What this app is

LowPoly64 is a retro 3D editor for building low-poly objects, character pieces and simple animations with JSON-first workflows.

Project page: https://github.com/IAnMove/LowPoly64

Basic workflow

1. Create or import

    2. Edit in the viewport

      3. Add animation when needed

        4. Export your result
