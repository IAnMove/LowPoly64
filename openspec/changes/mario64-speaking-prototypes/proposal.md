## Why
The first PSX hero now has usable geometry, but we need a contrasting rounded N64 character and working speech experiments to assess how faces could support future interactive characters.

## What Changes
- Preserve the authored Cloud recipe and deliver a new Mario64-inspired character with reusable rounded body, head, cap, overalls, rig, JSON and GLB.
- Add a small local speech laboratory comparing SVG viseme poses, deforming 2D pieces and a volumetric jaw.
- Drive mouths from audio intensity or authored timed visemes. Include playable local demo audio, custom audio input and optional user-initiated microphone input.
- Export reproducible speech cues and baked GLB animation samples, with actual renderer captures and documentation of prototype limitations.

## Capabilities
### New Capabilities
- `rounded-plumber-character`: reproducible rounded N64 character recipe and geometry.
- `speech-mouth-prototypes`: local comparison of audio-reactive 2D/SVG/3D mouths.

### Modified Capabilities

## Impact
Character Studio recipe profiles/catalog, new character geometry modules and speech modules, prototype UI, browser export validation and example artifacts. Existing Cloud recipe and geometry remain reproducible.
