## Why
The current PSX swordsman is technically editable but has a generic block silhouette, crown-like hair and a flat shoulder plate. The user wants visual improvement in five successive stages with actual editor screenshots.

## What Changes
- Add a reusable heroic body profile with shaped limbs, torso, hands and boots.
- Add a faceted expressive head, directed asymmetric hair, fitted clothing and equipment.
- Present the character in a pose independently of its reusable rig.
- Capture every stage in the real renderer and retain editable JSON/GLB examples.

## Capabilities
### New Capabilities
- `heroic-character-art`: expressive geometric humanoid profiles and staged visual review.

## Impact
Character Studio generators, semantic recipes/catalog and the visual example workflow. Existing recipes and rig contracts remain supported.
