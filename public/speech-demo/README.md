# Audio de demostración

Voz sintética Microsoft Helena Desktop (español de España), generada localmente con Windows SAPI. No pretende imitar la voz de ningún personaje.

phrase.wav: la misma frase para comparar intensidad y gestos automáticos. phrase.rhubarb.json guarda los 54 segmentos generados realmente con Rhubarb Lip Sync 1.14.0, reconocedor phonetic. vowels.wav: sonidos separados, con tiempos explícitos en vowels.cues.json. M/F son aproximaciones de la voz sintética; los controles manuales permiten comprobar esas formas.
